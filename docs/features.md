## Project Features

### 1. Add Income
Allows users to record income received from different sources. The transaction amount is added to the current balance.

### 2. Add Expense
Allows users to record expenses such as shopping, food, travel, and other daily spending. The amount is deducted from the current balance.

### 3. Deposit Money
Allows users to record money deposited into their account. The deposit amount increases the current balance.

### 4. Withdraw Money
Allows users to record money withdrawn from their account. The withdrawal amount decreases the current balance.

### 5. View Current Balance
Displays the current account balance based on the recorded transactions.

### 6. View Transaction History
Displays all recorded transactions, including transaction ID, date, type, amount, description, and balance.

### 7. Search Transactions
Allows users to find specific transactions using details such as transaction ID, description, or transaction type.

### 8. Filter Transactions
Allows users to filter transactions based on transaction type, minimum amount, or date range.

### 9. Sort Transactions
Allows users to arrange transactions by date, amount, or transaction ID.

### 10. Generate Bank Statement
Generates an organized bank statement for a selected date range, including transaction details, total credits, total debits, net movement, and transaction count.

### 11. View Financial Summary
Displays a summary of total income, total expenses, total deposits, total withdrawals, current balance, and total number of transactions.

### 12. Automatic Data Storage
Saves transaction records to a CSV file so that the data can be loaded again when the application restarts.

### 13. Input Validation
Includes methods for validating transaction amounts, checking date formats, and handling certain invalid inputs. Additional validation can be implemented to prevent invalid menu selections and incorrect transaction entries.

### 14. File Handling
Uses Java file-handling features to read and write transaction records and generate reports.

### 15. User-Friendly Menu
Provides a simple, menu-driven interface that allows users to access the application's features through the VS Code terminal.
