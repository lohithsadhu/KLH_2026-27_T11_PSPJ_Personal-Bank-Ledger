# ABSTRACT
The Personal Bank Ledger & Statement Generator is a Java-based application designed to help users maintain and manage their personal financial transactions efficiently. The system allows users to record income, expenses, deposits, and withdrawals in a structured ledger. Based on the recorded transactions, the application can generate a clear and organized bank statement for a specified date range. The main objective of the project is to reduce manual record-keeping efforts and make personal financial tracking easier and more organized. The system maintains transaction details such as transaction ID, date, transaction type, amount, description, and balance after each transaction. It automatically calculates the updated balance and provides features such as transaction history, searching, filtering, sorting, and financial summaries. The project is implemented using Java and demonstrates important programming concepts, including classes, objects, methods, conditional statements, loops, collections using `ArrayList`, and file handling. Transaction records are stored in a file for future retrieval, while generated bank statements are saved as text files. Overall, the application provides a simple and user-friendly approach to maintaining personal financial records and generating transaction-based bank statements.
